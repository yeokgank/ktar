# KTAR 한국시험평가원 홈페이지 시안 — 인수인계 노트

최종 갱신: 2026-11-05

## 1. 프로젝트 개요
- 정적 HTML/CSS/JS 시안. 빌드 도구 없음, 파일을 그대로 열거나 정적 서버로 서빙.
- 저장소: https://github.com/yeokgank/ktar (공개), 브랜치 `main`
- 미리보기: https://yeokgank.github.io/ktar/ (GitHub Pages, `main` 푸시 시 1~2분 내 반영)
- Figma: https://www.figma.com/design/8evvT45fc3eqYr4gmBw5Qs/ktar
- 로컬 확인: 저장소 루트에서 `python3 -m http.server 8000` 후 http://localhost:8000

## 2. 원 요구사항 (고객 전달 내용 요약)
- 벤치마킹: kitech.re.kr, wisestone.kr, kait.or.kr, kisa.or.kr
- 첫 화면에서 메인 비주얼 슬라이드와 주요 서비스 바로가기가 스크롤 없이 함께 보일 것
- 메인은 아래 4개 영역만 구성, 서비스 상세 설명은 메인에 두지 않음
  1. 메인 비주얼 슬라이드 3장
  2. 주요 서비스 바로가기 메뉴
  3. 회사소개 요약 + 상세 페이지 이동 버튼
  4. 견적 문의 폼
- 시험·인증·고객지원 상세는 상위/하위 메뉴 클릭 시 별도 페이지
- 서브페이지 구성에 대한 요구사항 문서는 없음 → 벤치마킹 비교 후 제안·확정한 안이 아래 3번

## 3. 확정된 메뉴 구조 (엑셀: `docs/ktar-menu-depth-v3.xlsx`)
| 대메뉴 | 페이지 | 경로 |
|---|---|---|
| KTAR 소개 | 기관 소개 | `about/intro.html` |
| | 오시는 길 | `about/location.html` |
| 시험 | 공인시험 | `test/certified.html` |
| | 일반시험(V&V) | `test/vv.html` |
| 인증 | GS인증 | `cert/gs.html` |
| | KC인증 | `cert/kc.html` |
| | 클라우드서비스확인제 | `cert/cloud.html` |
| 고객지원 | 견적문의 | 별도 페이지 없음, 메인 `index.html#inquiry` |

- 공지사항·성적서(발급/진위 확인)·자료실은 사용자 결정으로 삭제됨.
- 메인 퀵 메뉴 8개(교체안, 사용자 승인): 공인시험 / 일반시험(V&V) / GS인증 / KC인증 / 클라우드서비스확인제 / 기관 소개 / 오시는 길 / 견적 문의

## 4. 파일 구조
```
index.html            메인 (슬라이드, 퀵 메뉴, 회사소개 요약, 견적 폼)
about/ test/ cert/    서브페이지 7개
css/style.css         공통 + 메인 스타일, GNB 드롭다운, 모바일 메뉴
css/sub.css           서브페이지 전용 (배너, 좌측 LNB, 표, 가로 절차, 안내 박스, 문의 바 등)
tools/                서브페이지 생성기 (gen_subpages.py + 헤더/푸터 템플릿)
js/main.js            메인 슬라이드, 스크롤 시 헤더 고정
js/nav.js             모바일 메뉴 토글 (메인·서브 공통)
images/               로고(color/white), 히어로 SVG 3장, 소개 배경 SVG
docs/                 메뉴 뎁스 엑셀(v1, v3), 이 문서
```
- 로고 원본 PSD(`ktar_logo(X).psd`, `ktar_logo2(O).psd`)는 `.gitignore`로 제외되어 저장소에 없음. 최초 작업 컴퓨터의 프로젝트 폴더에만 있음. 사이트에는 변환된 PNG를 사용.
- 서브페이지 7개는 `tools/gen_subpages.py`로 생성함 (`python3 tools/gen_subpages.py .`). **페이지 본문·LNB·메뉴를 바꿀 때는 이 스크립트를 고치고 다시 실행**하면 7개가 함께 갱신됨. 헤더/푸터 원본은 `tools/tpl_head.html`, `tpl_tail.html`.
- 스크립트를 쓰지 않고 HTML을 직접 고치면 다음 실행 때 덮어써지므로 주의. 메인 `index.html`의 GNB는 별도 파일이라 메뉴 변경 시 같이 수정해야 함.

## 5. 현재 상태
- 완료: 메인 페이지, 서브페이지 7개(공공·시험기관 톤으로 개편: 좌측 LNB, 각진 표·목록 중심, 페이지별 다른 구성), GNB 드롭다운, 모바일 메뉴, 메인 퀵 메뉴 개편, GitHub Pages 배포
- 디자인 방향: 초기 시안의 둥근 카드·그라디언트·태그·FAQ 스타일이 AI 생성물 같다는 검토 의견으로 제거함. 벤치마킹 사이트(KITECH·KISA·KAIT)처럼 문서형 레이아웃 유지.
- 확인 범위: 크롬 데스크톱(1440)·모바일(375)에서 확인. Safari/Firefox 미확인.
- Figma: `main` 페이지에 `Main / Desktop 1440`, `Main / Mobile 375`, `Main Slide Assets`가 있고 `Components` 페이지에 컴포넌트가 있음. **메인 퀵 메뉴 개편, 서브페이지는 아직 Figma에 반영하지 않음** (메인 시안은 이전 퀵 메뉴 8개 기준).
- Figma MCP는 Starter 플랜 호출 한도에 걸려 쓰기 호출이 막혔던 이력이 있음. 한도 해제 시점은 문서화되어 있지 않음. 다른 컴퓨터에서는 Figma MCP 인증을 다시 해야 함.

## 6. 남은 작업
1. 샘플 문구를 실제 내용으로 교체 (아래 7번)
2. Figma: 이미지 에셋 보드(로고 color/white, 아이콘, 슬라이드 배경, 소개 배경) 정리, 퀵 메뉴 교체 반영, 서브페이지 시안 추가
3. 오시는 길의 실제 지도 연동 (현재는 CSS로 그린 자리표시)
4. 푸터의 개인정보처리방침·이용약관·이메일무단수집거부 페이지 또는 링크
5. 견적 문의 폼 실제 전송 처리 (현재 `action="#"`, 백엔드 없음)
6. 다른 브라우저 점검, 접근성·성능 점검

## 7. 임시(샘플) 값 목록 — 공개 전 교체 필요
- 메인: 상단 공지 문구·날짜, 대표전화 `00-0000-0000`, 슬라이드 문구 3종, 회사소개 요약 문구, 푸터 주소·전화·팩스·이메일
- 기관 소개: 인사말·원장 이름·사진 자리, 미션/비전/핵심 가치, 연혁(연도·내용 모두 임의), 조직·업무
- 오시는 길: 주소, 연락처, 교통 안내
- 시험·인증: 성적서 활용, 절차 단계, 제출 서류, 공인시험/일반시험 비교표, GS 평가 관점, KC 유형 표(세부 기준 미확정), 클라우드 확인 영역
- 각 서브페이지 하단에 "시안용 샘플" 안내 문구가 있음 (`.sample-note`). 확정 후 제거.
